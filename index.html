Cómo usar esta App

  • 1.
    Descarga Primero: Antes de empezar, usa el botón "Descarga 21 plantillas..." en la cabecera para tener tus herramientas de Excel listas.
  • 2.
    Filtra y Explora: Usa Categorías o la barra de búsqueda para encontrar el prompt que necesitas.
  • 3.
    Usa las Plantillas: Si ves "Usar Plantilla", haz clic. Te dirá *cuál* plantilla de tu pack usar (ej: "Plantilla 5"). Llénala con tus datos y luego usa el prompt.
  • 4.
    Copia Fácil: El botón "Copiar" pone el prompt en tu portapapeles.
  • 5.
    Ejecuta Directo: ChatGPT, Claude o Manus copian el prompt y abren la IA. Solo "Pega" (Ctrl+V).
  • 6.
    Navega por Páginas: Usa "Siguiente" y "Anterior" para ver todos los prompts.
